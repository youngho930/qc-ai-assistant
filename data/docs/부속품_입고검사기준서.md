# 부속품 입고검사기준서 (QC-IS-002)

> 포트폴리오 시연용으로 작성한 가상 문서입니다. 실제 사내 문서가 아닙니다.

## 적용 범위

협력업체로부터 입고되는 부속품 및 반제품에 적용한다.

## 공통 절차

입고 시 거래명세서와 실물 수량을 대조하고, 시험성적서 첨부 여부를 확인한다.
성적서가 누락된 경우 입고 보류하고 구매 담당자에게 통보한다.

## 샘플링 기준

| 입고 수량 | 검사 수량 | 합격 판정 개수 |
| --- | --- | --- |
| 1 ~ 50 | 5 | 0 |
| 51 ~ 500 | 13 | 1 |
| 501 ~ 1200 | 20 | 2 |
| 1201 이상 | 32 | 3 |

## 품목별 검사 항목

### 건식전극 (MM-115, SP-102)

- 전극 표면 도금 벗겨짐, 산화 흔적 없을 것
- 접촉 저항 20Ω 이하
- 핀 높이 편차 0.2mm 이내

### 귓불전극 (MM-002)

- 클립 파지력: 자중 이탈 없을 것
- 케이블 단선 여부 도통 시험
- 커넥터 삽입 후 유격 없을 것

### FPCB (TW-108)

- 패턴 단선, 쇼트 육안 및 도통 검사
- 굴곡부 크랙 없을 것
- 커넥터 핀 정렬 불량 없을 것

### 배터리 (LM-125)

- 무부하 전압 3.7V ~ 4.2V 범위
- 외관 부풀음, 누액 없을 것
- 인증 라벨 부착 확인

## 부적합 처리

불합격 로트는 전량 격리하고 협력업체에 반품 또는 선별 요청한다.
동일 업체에서 3개월 내 2회 이상 불합격이 발생하면 공급업체 평가에 반영한다.
