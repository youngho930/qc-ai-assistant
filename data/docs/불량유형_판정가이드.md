# 불량유형 판정 가이드 (QC-GD-003)

> 포트폴리오 시연용으로 작성한 가상 문서입니다. 실제 사내 문서가 아닙니다.

## 목적

검사자마다 판정이 달라지는 것을 막기 위해 자주 발생하는 불량의
등급과 처리 방향을 정리한다.

## 불량 등급 정의

- 치명 불량 (Critical): 사용자 안전 또는 측정 데이터 신뢰성에 직접 영향.
  발견 즉시 출고 중단하고 품질책임자에게 보고한다.
- 중결함 (Major): 제품 기능에 영향을 주어 사용이 어려운 수준. 불합격 처리한다.
- 경결함 (Minor): 기능에 영향 없는 외관 수준. 로트 내 허용 개수 이내면 합격.

## 유형별 판정

| 불량 유형 | 등급 | 처리 |
| --- | --- | --- |
| 배터리 부풀음, 누액 | 치명 | 즉시 격리, 로트 전량 검사 |
| 전극 임피던스 규격 초과 | 치명 | 불합격, 원인 조사 |
| 블루투스 미연결 | 중결함 | 불합격, 재작업 후 재검사 |
| 충전 불량 | 중결함 | 불합격, 재작업 후 재검사 |
| 조립 단차 0.5mm 초과 | 중결함 | 불합격, 재조립 |
| 표면 스크래치 3mm 이상 | 중결함 | 불합격, 커버 교체 |
| 표면 스크래치 3mm 미만 | 경결함 | 로트당 2개까지 허용 |
| 인쇄 위치 미세 틀어짐 | 경결함 | 로트당 2개까지 허용 |
| UDI 라벨 오탈자, 누락 | 치명 | 즉시 격리, 전수 확인 |

## 판정이 애매한 경우

기준 경계에 걸치는 경우 합격으로 처리하지 않는다.
검사자 단독 판단 대신 품질책임자 확인을 거치고, 판정 근거를 기록으로 남긴다.
동일 사유가 반복되면 본 가이드에 항목을 추가한다.
